## Sleep Tracker App 

Sleep Tracker is a web-based application that allows users to track and monitor their sleep habits. Users can log the date and times they fell asleep and woke up, rate their sleep quality as either good or bad, and view their previous sleep entries to keep track of their sleeping patterns over time. The application provides a simple way to record nightly sleep information and review past entries in one place.

## Features
Log Sleep: Record the date, time you fell asleep, and time you woke up.\
Rate Sleep Quality: Rate each night's sleep as either good or bad based on your personal experience.\
View Sleep History: Browse previously saved sleep entries and review recorded sleep information.\
Track Sleep Habits: Keep a history of sleep times and quality ratings to help monitor sleeping patterns over time.\
Public Access: No authentication required. Anyone with access to the application can view and manage sleep entries.

## Tech Stack
Frontend: EJS, HTML, CSS, JavaScript, Bootstrap\
Backend: Node.js, Express.js\
Database: MongoDB Atlas with Mongoose

## What I Learned
Structuring an Express.js application using the MVC architecture, separating database operations, application logic, and user interface components to create more organized and maintainable code.\
Implementing CRUD functionality to create, view, update, and delete sleep records using MongoDB and Mongoose.\
Working with EJS to render dynamic content and display saved sleep entries.\
Handling date and time inputs to record and organize sleep information.\
Implementing a sleep quality rating system to allow users to track their personal sleep experiences.\
Building a user-friendly interface for recording and reviewing sleep history.
